# Tic-Tac-Toe Game 

A simple browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## How to Play

1. Open `game.html` in your web browser.
2. Click an empty square to make a move.
3. The game alternates between O and X.
4. Get three matching symbols in a row to win.

## Project Files

- `game.html` — The game page and board
- `game.css` — The styles and layout
- `game.js` — The game logic

## Technologies Used

- HTML
- CSS
- JavaScript

## Running the Game

No installation is needed. Download or clone the project, then open `game.html` in a browser.
